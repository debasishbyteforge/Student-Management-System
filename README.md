# Student Management System

## Project Description
A simple web application for managing student information.

## Features
- Add student details
- View student records
- Delete student records
- Student login interface
- Simple and user-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## Project Files
- index.html - Main student management page
- Login.html - Student login interface
- README.md - Project documentation

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.

## Note
This is a beginner-level project. Student records are
temporary, and login authentication is not implemented.
