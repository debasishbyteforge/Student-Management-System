Student Management System

Project Overview

The Student Management System is a web-based project developed using HTML, CSS, and JavaScript. It provides a simple interface for managing student information.

Features

- Student registration form
- Add student records
- Display student records in a table
- Delete student records
- Validate duplicate roll numbers
- Save student records using browser Local Storage
- Login page interface

Technologies Used

- HTML — webpage structure
- CSS — webpage styling
- JavaScript — functionality and validation
- Local Storage — saving student records in the browser
- Git and GitHub — version control and project hosting

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using the Live Server extension.
4. Use the website in your browser.

Project Status

The basic student record management functionality and login page interface have been created and tested.
